# Joption 官網

內容全部是 `content/` 裡的文字檔，選單、FAQ 目錄、上下頁、搜尋都由程式自動產生。

## 新增一頁

1. 雙擊 `新增頁面.bat`，選分類、打標題，記事本會自動打開。
2. 寫內容、存檔。
3. 雙擊 `預覽網站.bat` 看結果，等十幾秒瀏覽器會自動打開。預覽開著時，存檔後等十幾秒再重新整理網頁就會更新。
4. 確認沒問題後，雙擊 `發布網站.bat`，約 1 分鐘後網站就更新了。

截圖放上去之前，先確認沒拍到序號或身分證字號：這個 repo 是公開的，傳上去就算刪掉也還留在紀錄裡。

檔案放進哪個資料夾，就出現在哪個選單下面，不必改任何目錄。

## 每頁開頭的設定

```
---
title: 什麼是幽靈單
order: 480
summary: 顯示在目錄卡片上的一句話。
hidden: true
---
```

| 欄位 | 用途 |
|---|---|
| `title` | 頁面標題（必填） |
| `order` | 排序，數字小的在前；沒寫就排最後 |
| `summary` | 目錄卡片上的說明，可不寫 |
| `hidden` | 寫 `true` 就不出現在選單和搜尋，但網址仍可開 |

## 內文寫法

| 想要的效果 | 這樣寫 |
|---|---|
| 小標題 | `## 小標題`、`### 更小的標題` |
| 粗體 | `**粗體**` |
| 紅色強調 | `==紅字==` |
| 連結 | `[文字](網址)` |
| 按鈕 | `[文字](網址){.btn}` |
| 清單 | 每行開頭 `- ` |
| 圖片 | 圖檔放 `content/images/`，寫 `![說明](/images/檔名.png)` |
| YouTube | `[[youtube:影片代碼]]` |
| 互動工具 | HTML 放 `content/tools/`，寫 `[[tool:檔名]]` |
| 內嵌試算表等網頁 | `[[embed:網址]]` |

## 其他要改的地方

- 網站名稱、首頁卡片、頁尾連結：`site.toml`
- 顏色和版面：`theme/site.css`

## 網址

網站目前的網址是 https://joption-tw.github.io/joption-site/ ，設定在 `site.toml` 的 `url`。之後要綁 www.joption.com.tw，把這一行改掉再改 DNS 就好，內文連結都不用動。

檔案路徑就是網址，例如 `content/faq/什麼是幽靈單.md` 是 `/faq/什麼是幽靈單/`。內文的站內連結和圖片一律從 `/` 開頭寫，程式會自動補上網址前段。改檔名會改網址，別人存的舊連結就會失效。

產生網站時如果站內連結或圖片打錯，畫面會列出「注意：…」。

## 第一次在新電腦上使用
