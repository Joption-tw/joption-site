**平衡式 = Call 總點數 ÷（Call 總點數 + Put 總點數）**

## 一開始

大盤約 45000，兩邊點數差不多。

| | 部位 | 總點數 |
|---|---|---|
| Put | Sell Put 44800，20 口 | 1,740 |
| Call | Sell Call 45200，25 口 | 1,800 |
| **合計** | | **3,540** |

平衡式 1800 ÷（1740 + 1800）= **50.8%**

## 經過幾個小時，行情動了

| | 下跌 100 點 | 上漲 100 點 |
|---|---|---|
| Put 總點數 | 2,240 | 1,240 |
| Call 總點數 | 1,200 | 2,150 |
| 合計 | 3,440 | 3,390 |
| 平衡式 | ==34.9%==（失衡） | ==63.4%==（失衡） |

## 重新平衡

| | 下跌後 | 上漲後 |
|---|---|---|
| 錢夠多時 | Sell Call | Sell Put |
| 錢不夠時 | Buy Put | Buy Call |
| 調整後的 Put | Sell Put 44800，==15 口==（1,680 點） | Sell Put 44800，20 口 + ==Sell Put 45000，5 口==（1,690 點） |
| 調整後的 Call | Sell Call 45200，25 口 + ==Sell Call 45100，10 口==（1,800 點） | Sell Call 45200，==20 口==（1,720 點） |
| 平衡式 | **51.7%** | **50.4%** |

平衡之後，繼續靠**時間價值衰退而產生獲利**。
