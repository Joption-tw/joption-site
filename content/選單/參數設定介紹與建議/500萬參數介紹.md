**選擇權雙賣平衡下單機：500 萬參數建議**（2025/07/18）

> 這是個人參考參數，不代表適合每個人。請依自己的資金和風險承受度調整，選擇權交易有風險。

## 雙賣建倉

| 項目 | 設定 |
|---|---|
| 掛單價格 | 不二價 |
| 建倉範圍 | 價外 3 檔 至 價外 1 檔 |
| 下單速度 | 每次最多 2 口，間隔 15 秒 |
| 防呆機制 | 不下總成交量低於 100 口的檔位 |
| 預約時間 | 08:50:00、21:20:00 |
| 停止條件 | 保證金不足總市值的 30% 時結束 |
| 完成後啟動 | C/P 比值平衡法、閃電清倉 |

![雙賣建倉的設定畫面](/images/500萬參數介紹/02.png)

## C/P 比值平衡

| 項目 | 設定 |
|---|---|
| 執行模式 | AI 智能執行，範圍 0.43～0.57 |
| 比值範圍 | 0.42～0.58 |
| 超出時賣出 | 價外 2 檔，中間偏難價，1 口 |
| 同時買進 | 價外 32 檔，中間偏難價，1 口 |
| 優先平倉價內 | 開啟 |
| 下單間隔 | 每 7 秒一次，每筆委託 4 秒未成交就取消 |
| 保證金 | 餘額不足總市值的 30% 時，改用買進取代賣出 |
| 防呆機制 | 不下總成交量低於 100 口的檔位 |

下單方向：小於下限時 Sell Call + Buy Put；大於上限時 Sell Put + Buy Call。

![C/P 比值平衡的設定畫面](/images/500萬參數介紹/03.png)

## 閃電清倉

| 項目 | 設定 |
|---|---|
| 掛單價格 | 中間偏難價 |
| 清倉範圍 | 價外 31 檔 至 價格 1,000 點 |
| 下單速度 | 每一檔位每次 1 口，間隔 10 秒 |
| 清除對象 | 全部庫存，Call、Put 全部 |
| 智能平衡清倉 | 開啟，確保 C/P 比值介於 0.47～0.53 |
| 預約時間 | 13:21:14、02:21:14 |
| 完成後啟動 | 雙賣建倉 |

![閃電清倉的設定畫面](/images/500萬參數介紹/04.png)

## 保證金回收（進階，結算日使用）

| 項目 | 設定 |
|---|---|
| 啟動條件 | 保證金餘額低於總市值的 30% |
| 尋找檔位 | Call、Put 都找價外 300 點 |
| 掛單方式 | 以不二價買入，每 30 秒 1 口 |
| 未成交處理 | 每筆委託 181 秒未成交就取消 |
| 防呆機制 | 不下總量低於 100 口的檔位 |
| 智能下單 | 開啟，自動挑回收效果較好的一邊 |
| 同時下單 | Call、Put 買賣差 ≦ 0 口時，兩邊同時下 |
| 暫停條件 | 買方口數大於賣方 5 口時，暫停該邊回收單 |

![保證金回收的設定畫面](/images/500萬參數介紹/05.png)

## 指定清倉（進階）

| 項目 | 設定 |
|---|---|

| 掛單價格 | 不二價 |
| 清倉範圍 | 價內 2 檔 至 價內 4 檔 |
| 下單速度 | 每次最多 1 口，間隔 60 秒 |
| 清除對象 | 全部庫存，Call、Put 全部 |
