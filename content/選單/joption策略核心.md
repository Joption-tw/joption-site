**Joption = 雙賣策略 + 平衡策略**

- **策略核心：** 自動化雙賣，加上即時平衡調整
- **獲利來源：** 時間價值衰減、區間震盪、系統化風險控制
- **優勢：** 克服貪婪、恐慌、遲疑等人性弱點，追求穩定、可持續的收益曲線

## 策略口訣

**中性（多、空）雙賣策略 + 永遠的平衡**

就像翹翹板，Call 和 Put 要維持平衡。

![翹翹板兩端分別是 Call 和 Put，代表兩邊部位要維持平衡](/images/joption策略核心/01.png)

<a id="h.tob03vly3afn"></a>

## 一、Joption 的策略原則

1. **核心策略：雙賣平衡**
    - 同時賣出 Call 與 Put（選擇權賣方），建立中立的部位。
    - 系統自動計算 Call、Put 部位的價值比，持續監控是否失衡。
    - 失衡超過設定範圍（例如 ±5%）就自動調整，避免一邊風險過大。
2. **風險即時監控**
    - 系統自動偵測保證金、履約價分布與 Delta 風險。
    - 一旦出現過度集中或單邊行情，就觸發清倉或偏移調整。
3. **自動化調整邏輯**
    - **比值調整：** Put、Call 市值比過度傾斜時，補單或平倉修正。
    - **多口清倉：** 部位超過設定口數或保證金風險提升時，自動分批出場。
    - **時間與價差控制：** 接近結算日或行情急劇變動時，自動收斂部位。

<a id="h.fzr9xra1ydlm"></a>

## 二、Joption 的獲利來源

1. **時間價值衰減（Theta 收益）**
    - 選擇權會隨著時間流逝不斷失去價值。
    - Joption 把握這個特性，當賣方收權利金，同時持續控管風險。
2. **維持部位平衡**
    - 人工交易容易因情緒延遲而失衡，造成一邊虧損暴增。
    - Joption 用自動調整維持「小賺大穩」的結構，降低一次大賠的機會。
3. **波動率收斂效應**
    - 在無趨勢或區間震盪的行情，賣方比較有利。
    - Joption 把握「行情沒方向，但時間在走」的特性，持續累積權利金。
4. **系統化風險控制**
    - 不靠預測方向，靠控風險、穩保證金。
    - 幫助降低爆倉或一次大虧的風險。

## 雙賣策略的基本圖形

| 組合 | 策略 | 適合的預期 |
|---|---|---|
| **兩口單：** Sell Call + Sell Put | 賣出跨式 | 狹幅整理 |
| | 賣出勒式 | 區間整理 |
| **四口單：** Sell Call + Sell Put + Buy Call + Buy Put | 蝶式價差 | 狹幅整理，同時控制上下檔風險 |
| | 禿鷹式價差 | 區間整理，同時控制上下檔風險 |

## 用賭場來比喻：當莊家

**不預測行情，只設區間收租**

- 莊家不猜漲跌，只規劃一個震盪區間，收兩邊的權利金。
- 就像賭場不管你押紅押黑，只統計機率、設限額。

**同時賣出 Call 和 Put，收雙邊權利金**

- 賣出一組價外的 Call 和 Put。
- 每一邊都可能歸零，莊家有機會兩邊都賺。
- 波動小時兩邊都收下，就像莊家抽成。

</div>

</div>

**每 5 秒一局，重新開盤再收一次**

- 與其一次賭大，不如每一口都像賭桌重新開局。
- 利用台指選擇權流動性高的特性，由自動化系統日內快速調倉、高頻下單。

**動態調整賠率，維持莊家優勢**

- 市場波動大時，拉遠履約價。
- 市場波動小時，增加持倉。
- 搭配 Delta 中性、Gamma 調整，以及 IV 高低的選擇。

## 平衡策略實例

**平衡式 = Call 總點數 ÷（Call 總點數 + Put 總點數）**

### 一開始

指數 16800，平衡式 680 ÷（650 + 680）= **51.1%**，兩邊平衡。

| | 部位 | 總點數 |
|---|---|---|
| Put | Sell Put 16700，20 口 | 650 |
| Call | Sell Call 16900，25 口 | 680 |
| **合計** | | **1,330** |

### 幾個小時後，行情動了

| | 下跌 50 點（指數 16750） | 上漲 50 點（指數 16850） |
|---|---|---|
| Put 總點數 | 850 | 400 |
| Call 總點數 | 450 | 800 |
| 合計 | 1,300 | 1,200 |
| 平衡式 | **34.6%**（失衡） | **66.7%**（失衡） |

### 重新平衡

| | 下跌後 | 上漲後 |
|---|---|---|
| 錢夠多時 | 多賣 Call（Sell Call） | 多賣 Put（Sell Put） |
| 錢不夠時 | 買進 Put（Buy Put） | 買進 Call（Buy Call） |
| 調整後的 Put | Sell Put 16700，==15 口==（600 點） | Sell Put 16700，20 口 + ==Sell Put 16800，5 口==（630 點） |
| 調整後的 Call | Sell Call 16900，25 口 + ==Sell Call 16850，10 口==（650 點） | Sell Call 16900，==18 口==（650 點） |
| 平衡式 | **52.0%** | **50.8%** |

平衡之後，繼續靠**時間價值衰退**產生獲利。

## 注意事項

- **遵守初衷：** 嚴格執行賺取時間價值。不硬凹，要捨得，該調整平衡時就及時調整。
- **平衡式維持在 0.4～0.6 之間：** 見仁見智，這是我個人認為的黃金比例。
- **保證金預留 30%：** 留在手上，當作大漲大跌時的緊急備用金。
- **放假前要保護：** 記得讓 Sell Put 口數 ≦ Buy Put 口數，防止黑天鵝（跳空）。
