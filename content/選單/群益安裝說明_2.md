## 1. 安裝前確認

動手前，先確認這四件事都已經完成：

- 已在群益期貨開戶
- 已開通群益 API 使用權限
- 已完成線上 API 簽訂
- 已向群益期貨營業員取得 Joption 註冊碼（金鑰）

> 需要遠端協助時，請先安裝 AnyDesk，方便歐大連進去幫你看。

## 2. 下載

安裝包**只有一個檔案，不用解壓縮**。點下面的按鈕，瀏覽器就會**直接開始下載「群益安裝包.exe」**，不用再去雲端硬碟找檔案。

[下載群益安裝包（點一下就開始）](https://drive.usercontent.google.com/download?id=1D6EFz-dDcflXwW1oS0zWv4bCafKrjNBX&export=download&confirm=t){.btn}

- 下載完成後，在瀏覽器的下載清單（或「下載」資料夾）**雙擊「群益安裝包.exe」**就能開始安裝，接著看下面的步驟一。
- 瀏覽器可能提示「這個檔案不常被下載」，選**「保留」**。
- 想看手冊或其他檔案：[群益下載點](https://drive.google.com/drive/folders/1iYm4R9PSRWFTI09oC2jRp2go16h7Oi6U)（安裝及簡易操作手冊、大改版安裝說明、完整操作手冊、當沖懶人包）。

安裝包會幫你裝下面這些東西，不用自己一個一個找：

| 用途 | 安裝包做什麼 | 裝在哪裡（預設） |
|---|---|---|
| VC++ 執行環境 | 需要的兩個版本，這台電腦已經裝過的會自動略過 | Windows 系統 |
| 群益 API | 下載附帶的 x64 版（2.13.59.7）並註冊 | `C:\Capital\2.API\API` |
| 群益憑證 | 下載憑證精靈，裝完 API 自動打開 | `C:\Capital\1.憑證安裝` |
| Joption 下單機 | 下載最新版並解壓縮、建桌面捷徑 | `C:\Capital\Joption雙賣平衡下單機` |

> **安裝包不會碰你的帳號、密碼、註冊碼和憑證。** 這些都是你自己在憑證精靈和 Joption 輸入的，安裝包看不到，也不會儲存。

> 安裝過程需要**網路**（會從雲端硬碟下載檔案）和**系統管理員權限**。如果 Windows 跳出「已保護您的電腦」，點「其他資訊」→「仍要執行」。

## 3. 步驟一：執行安裝包

> **安裝有兩個硬性規定，一定要遵守：**
>
> - 請用安裝包附的 API，**不要自己另外下載其他版本**。
> - **安裝完成後，資料夾不可以再移動。** 群益 API 註冊的是這個資料夾的位置，預設是 `C:\Capital`。想裝在別處，請在安裝前就選好。

1. 雙擊下載好的 **群益安裝包.exe**。跳出「是否允許…」時按**「是」**。
2. 確認「安裝到」的位置（預設 `C:\Capital`，要換位置按「選擇…」）。
3. 兩個勾選維持預設（在桌面建立捷徑、裝完 API 後開啟憑證安裝程式），按**「開始安裝」**。

![安裝包主視窗：確認位置後按「開始安裝」](/images/群益安裝說明_2/02.png)

4. 等進度條跑完，**約 1 分鐘**（網路慢會久一點，請不要關閉）。安裝包會依序：讀取雲端清單 → 下載 → 解壓縮 → 安裝 VC++（已裝過會略過）→ 註冊群益 API → 建立桌面捷徑。

![下載中：視窗裡會一行一行顯示做到哪一步](/images/群益安裝說明_2/03.png)

5. 看到「**檔案都裝好了**」，群益憑證精靈會自動跳出來。

![檔案都裝好了，等憑證精靈](/images/群益安裝說明_2/04.png)

## 4. 步驟二：安裝群益憑證

- 在「群益金融集團憑證精靈」畫面輸入**身分證字號**和**密碼**，照畫面流程操作到完成。
- 憑證裝好後，把憑證精靈**關掉**。
- 關掉的瞬間，安裝包下面的**「下一步：開啟 Joption」**會亮起來。

![群益憑證精靈（安裝包自動打開）](/images/群益安裝說明_2/05.png)

![憑證精靈關掉後，「下一步」亮起](/images/群益安裝說明_2/06.png)

> 這台電腦**已經裝過憑證**？直接按旁邊的**「略過憑證」**，「下一步」就會亮起來。

## 5. 步驟三：Joption 第一次啟動

- 按**「下一步：開啟 Joption」**，Joption 會自動打開。
- 第一次啟動時，會依序跳出三個視窗：**身分證字號 → 密碼 → 註冊碼（金鑰）**。這一步只有第一次需要，註冊碼請向群益期貨營業員索取。
- 看到成功登入的主畫面，就完成了。按安裝包的「完成」關閉它。

> 以後要開 Joption，直接點桌面的 **Joption** 捷徑就好。

## 6. 重新安裝或刪除程式

已經裝過的電腦，再執行一次「群益安裝包.exe」，會先跳出選擇視窗：

![再次執行安裝包：重新安裝／刪除程式／取消](/images/群益安裝說明_2/09.png)

| 選項 | 做什麼 |
|---|---|
| **重新安裝** | 沿用原來的位置，重新下載並覆蓋程式檔，清掉舊版殘留。你的 `conf` 設定（含帳密檔）會保留，不會被預設值蓋掉。 |
| **刪除程式** | 刪除安裝包放的三個資料夾（1.憑證安裝、2.API、Joption雙賣平衡下單機）和桌面捷徑，並取消註冊群益 API。視窗裡的「刪除時保留我的設定與紀錄」預設是勾的；取消勾選，連 `conf` 一起刪。 |

- 這兩個動作 **Joption 還開著時都不能做**，請先把它關掉。
- 刪除**不會動**：同一個資料夾裡其他不是安裝包放的東西、VC++ 執行環境、你的憑證。

## 7. 安裝後設定

程式能正常登入之後，再設定下面這幾項。

| 設定 | 用途 |
|---|---|
| Google Sheet 上傳與績效分享 | 把帳戶資料上傳到 Google Sheet，和同學會分享績效（[設定步驟](/faq/如何分享績效/)） |
| Telegram | 接收程式通知（[設定步驟](/faq/telegram通知設定/)） |
| 更換商品（換週、換月） | 切換要監控的選擇權合約 |

> 更換商品後要**存檔並重新啟動程式**，新商品的報價才會下載。

## 8. 每日自動重開機與自動開啟 Joption

建議每天夜盤結束後、早上 5:30 之後重新開機一次。這兩件事都用 Windows 的「工作排程器」完成。

### 設定每日重開機

- 從 Windows 系統管理工具開啟**「工作排程器」**。
- 點**「建立工作」**。
- 在**「觸發程序」**選**「每週」**，勾選要重新開機的星期和時間。
- 在**「動作」**的程式欄輸入 `shutdown`，**「新增引數」**欄輸入 `/r`。

### 設定自動開啟 Joption

- 一樣開啟「工作排程器」，點「建立工作」。
- 在「觸發程序」選「每週」，勾選要自動開啟的星期和時間。**時間要排在重開機之後。**
- 在「動作」選取要執行的 Joption 程式：`C:\Capital\Joption雙賣平衡下單機\Joption.exe`。

## 9. 序號到期後更新

- 向營業員索取更新後的序號。
- 打開 `C:\Capital\Joption雙賣平衡下單機\conf` 裡的 `pw.txt`。
- 把**第三行**的內容整行換成新序號。
- 存檔。

相關說明：[更換金鑰流程](/faq/更換金鑰流程/)

## 10. 程式改版更新

**最簡單的方法：** 直接在程式裡按「更新版本」就能更新，不用重新下載。步驟請看[如何更新程式](/faq/如何更新程式/)。

如果要用安裝包更新：再執行一次「群益安裝包.exe」，選**「重新安裝」**。它會下載最新版、清掉舊版殘留，並**保留你原有的 `conf` 設定**（帳號密碼和各項參數都不會被蓋掉）。

## 11. 常見問題

### Joption 顯示「登入失敗」怎麼辦？

群益 API 本身通常沒問題，登入失敗最常見的原因是**身分證字號、密碼或註冊碼打錯**，或是**憑證沒有裝好**。

- 先確認憑證精靈最後有顯示「成功」。
- 如果是輸入錯了：關掉 Joption，把 `C:\Capital\Joption雙賣平衡下單機\conf\pw.txt` 刪掉，再開 Joption，它會重新請你輸入身分證字號、密碼、註冊碼。

### 安裝到一半網路斷了，或下載失敗？

再執行一次「群益安裝包.exe」，按「開始安裝」重來即可，不需要先刪除。

### 提示「Joption 還開著」，不能重新安裝或刪除？

請先把 Joption 關掉（視窗右上角 X，或在工作列、右下角系統匣找到圖示右鍵「結束」），再回來按。

### 可以裝在別的位置嗎？

可以，在「安裝到」按「選擇…」選好位置。但裝好之後**不能再搬移**，因為群益 API 註冊的是那個位置。

### 這台電腦原本就有群益 API，會怎樣？

安裝包會把群益 API 註冊成它安裝的那一份（版本 2.13.59.7）。電腦上其他用到群益 API 的程式，之後也會使用這一份。

### 同一個身分證可以同時開好幾份 Joption 嗎？

不建議。同一個身分證在多個程式同時登入群益，可能會互相把對方踢下線，請特別留意。
