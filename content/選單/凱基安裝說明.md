**凱基選擇權雙賣平衡下單機：安裝及簡易操作手冊**（2025/10/03）

## 開戶及設備要求

### 開戶要求

開立選擇權戶頭時，請開通以下交易功能：

- 僅限凱基期貨帳戶使用
- 開通 API 使用權限
- 開通 250 檔報價
- 一個帳戶至少可以 4 個同時登入 API
- 開通夜間組單功能

### 資金建議：100 萬以上

- **建倉部位規模：** 同時賣出 Call 與 Put，資金約可建立 6～8 口部位。
- **彈性不足：** 口數偏少，調整與平衡的空間有限。

### 電腦配備

| 項目 | 建議 |
|---|---|
| CPU | i7 |
| 記憶體 | 64G |
| 固態硬碟 | 256G 以上 |
| 機型 | 桌上型電腦，不建議筆電 |
| 使用方式 | 專用電腦，不要與小孩共用 |

參考報價（2024 年 1 月），合計 29,900 元：

![電腦配備參考報價單](/images/凱基安裝說明/06.jpg)

### 網速要求

- 中華電信網路較好。
- 網路速度基本要達到 100MB。
- 參考：中華電信 1G/1G（下載／上傳）月租 1,300 元。

==網路不求快，但求穩定不斷線。==

## 安裝教學

### 安裝前確認

- API 使用權限已開通
- 250 檔報價已開通
- 一個帳戶至少可以 4 個同時登入 API
- 夜間組單已開通

### 取得程式

下載網址請洽所屬營業員。下載後會有三個資料夾：

- `1. 憑證元件`
- `2. API申請`
- `JOption_1.1.0.2`

![下載後的三個資料夾與裡面的檔案](/images/凱基安裝說明/10.jpg)

### 把權限（UAC）調到最低

權限調到最低，安裝過程比較方便操作。

1. 點 Windows 開始。
2. 搜尋 `UAC`。
3. 開啟「變更使用者帳戶控制設定」。
4. 把滑桿拉到最低「不要通知」，按確定。

![搜尋 UAC 並把滑桿拉到最低的畫面](/images/凱基安裝說明/11.jpg)

### 安裝三步驟

1. 安裝凱基的憑證
2. 安裝 API
3. 安裝凱基雙賣平衡下單機

需要協助的話，請先安裝 AnyDesk。

### 步驟一：安裝憑證

依照凱基的[憑證安裝方式說明](https://www.kgieworld.com.tw/uploadfiles/euploadfile/%E6%86%91%E8%AD%89%E4%B8%AD%E5%BF%83%28Web%29%E6%93%8D%E4%BD%9C%E8%AA%AA%E6%98%8E.pdf){.btn}操作。

看到下面這個畫面，憑證狀態顯示「有效」，就表示安裝完成。

![凱基憑證工具顯示憑證有效的畫面](/images/凱基安裝說明/13.jpg)

### 步驟二：申請 API

流程是：**登入申請 → 線上簽署 → 程式測試 → 成功通知**。

API 測試完成後，一天內會以 E-mail 通知結果。API 帳號權限最遲在收到通知的隔日生效。

1. **找到入口：** 到凱基期貨網站的 API 專區，選「凱基期貨 API」，點「立即申請」裡的「簽署線上申請」。
2. **登入：** 輸入身分證字號、電子交易密碼，勾選「我不是機器人」後登入，再把類別切換至期貨。
3. **申請：** 點「申請」按鈕開始簽署同意書，也可以在畫面右方確認帳號的「簽署」及「API 申請」狀態。
4. **簽署同意書：** 勾選「我已詳細閱讀，並同意內容項目」，點「同意」，訊息提示「API 同意書簽署成功」。
5. **確認個人資料：** 確認電子信箱、手機號碼，點「API 申請」開啟引導網頁。

API 是依帳號申請。如果有多個期貨帳號，要分別申請。

| 「簽署」狀態 | 「API 申請」狀態 | 會前往 |
|---|---|---|
| X | X | 全球交易中心／線上簽署 |
| V | X | API 申請 |

### 步驟二：API 軟體測試

1. **下載測試軟體：** 在 API 測試軟體頁面，下載 API 元件和驗證小工具。
2. **申請驗證：** 輸入 ID、密碼、分公司、帳號，點「API 申請驗證」。
3. **確認結果：** 訊息出現「API 驗證成功」才算驗證完成。
4. **等候通知：** 開通完成後，系統會依客戶申請留存的 Mail 自動發送電郵通知。

如果需要 API 自行開發程式的測試環境，請所屬業務員寫信至 kgif@kgi.com，主旨寫「因客戶申請 API 自行開發程式，需使用測試環境」，內容附上姓名、身分證號、分公司、期貨帳號。

### 步驟二：安裝下單 API

1. 打開資料夾 `KGI_Joption\2. API\3.TradeComExample_20240516\TradeComExample\bin\Release`。
2. 執行 `TradeComExample`，會閃一下黑色視窗。
3. 看到下面這個視窗，就表示已經完成，關掉即可。

![TradeCom 範例程式視窗，看到它代表安裝完成](/images/凱基安裝說明/16.jpg)
