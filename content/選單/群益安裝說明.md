## 1. 安裝前確認

動手前，先確認這四件事都已經完成：

- 已在群益期貨開戶
- 已開通群益 API 使用權限
- 已完成線上 API 簽訂
- 已向群益期貨營業員取得 Joption 註冊碼（金鑰）

![線上 API 簽訂畫面](/images/群益安裝說明/02.png)

> 需要遠端協助時，請先安裝 AnyDesk，方便歐大連進去幫你看。

## 2. 下載

所有安裝檔都在「群益JOPTION下單機下載」這個 Google 雲端硬碟資料夾，主程式**以資料夾內最新的版本為準**。

[到群益下載點](https://drive.google.com/drive/folders/1iYm4R9PSRWFTI09oC2jRp2go16h7Oi6U){.btn}

![群益JOPTION下單機下載資料夾：下載 Joption完整版壓縮檔，安裝及操作手冊可下載參考學習](/images/群益安裝說明/01.png)

- **下載這一個壓縮檔案：** Joption完整版（例如 Joption完整版20261001x64.zip）。
- **安裝及操作手冊可下載參考學習：** 安裝及簡易操作手冊、大改版安裝說明、完整操作手冊、當沖懶人包。
- **舊版本** 資料夾放的是以前的版本，一般不用下載。

解壓縮後會看到三個資料夾，剛好對應三個步驟：

![壓縮檔裡的憑證安裝、CapitalAPI_2.13.54.8、new API-Joption 三個資料夾](/images/群益安裝說明/03.png)

| 用途 | 檔案 | 用在哪一步 |
|---|---|---|
| 群益憑證 | RAWINAPP.EXE | 步驟一 |
| VC++ 執行環境 | vcredist_x86.exe（Microsoft Visual C++ 2010 Service Pack 1 MFC 可轉散發套件） | 步驟二 |
| 群益 API | CapitalAPI_2.13.54.8，內含「元件/X86/install.bat」 | 步驟二 |
| Joption 主程式 | Joption完整版壓縮檔（資料夾內最新版） | 步驟三 |

## 3. 步驟一：安裝群益憑證

**判斷標準：能順利登入「群益策略王」，憑證就裝好了。**

1. 執行 **RAWINAPP.EXE**。

![「1.憑證安裝」資料夾裡的 RAWinApp.exe](/images/群益安裝說明/04.png)

2. 出現憑證程式畫面後，照畫面流程操作到完成。

![群益憑證程式畫面，輸入身分證字號和密碼](/images/群益安裝說明/05.png)

3. 開啟群益策略王，確認可以正常登入。

![群益贏家策略王](/images/群益安裝說明/07.png)

> 登不進策略王，就先停在這一步處理，不要往下裝。

## 4. 步驟二：安裝 CapitalAPI 2.13.54.8

API 有兩個硬性規定，一定要遵守：

- **版本必須是 CapitalAPI_2.13.54.8**，不能用其他版本。
- **安裝完成後，資料夾不可以再移動。** 請先把 API 資料夾放到打算長期保留的位置，再開始安裝。

1. 安裝 **vcredist_x86.exe**（Microsoft Visual C++ 2010 Service Pack 1 MFC 可轉散發套件）。

![vcredist_x86.exe](/images/群益安裝說明/08.png)

2. 進入 API 資料夾裡的 **「元件 / X86」**，找到 **install.bat**。

![元件/x86 資料夾裡的 install.bat](/images/群益安裝說明/09.png)

3. 在 **install.bat** 上按滑鼠右鍵，選 **「以系統管理員身分執行」**。

![在 install.bat 按右鍵，選以系統管理員身分執行](/images/群益安裝說明/10.png)

4. 跳出「DllRegisterServer…成功」的視窗，按「確定」，API 就裝好了。

![RegSvr32 顯示註冊成功](/images/群益安裝說明/11.png)

## 5. 步驟三：安裝 Joption 並第一次啟動

Joption 不需要安裝程式，解壓縮後就能直接執行。

1. 把 Joption 主程式壓縮檔解壓到合適的位置，例如桌面。

2. 進入解開的資料夾，執行 **Joption.exe**。

![new API-Joption 資料夾裡的 joption.exe](/images/群益安裝說明/12.png)

3. 第一次啟動時，會依序跳出三個視窗：**身分證字號 → 密碼 → 註冊碼（金鑰）**。這一步只有第一次需要，註冊碼請向群益期貨營業員索取。

![第一次啟動：輸入身分證字號](/images/群益安裝說明/13.png)

![接著輸入密碼和金鑰](/images/群益安裝說明/14.png)

4. 看到成功登入的主畫面，就完成了。

![成功登入的主畫面](/images/群益安裝說明/24.png)

> **從舊版換到新版，不必重新輸入註冊碼：** 把舊程式的 **pw.txt** 複製到新程式的 **conf** 目錄就好。

![把舊程式 conf 裡的 pw.txt 複製到新程式的 conf](/images/群益安裝說明/15.png)

## 7. 每日自動重開機與自動開啟 Joption

建議**每天夜盤結束後、早上 5:30 之後重新開機一次**。這兩件事都用 Windows 的「工作排程器」完成。

### 設定每日重開機

1. 從 Windows 系統管理工具開啟 **「工作排程器」**。
2. 點 **「建立工作」**。
3. 在 **「觸發程序」** 選 **「每週」**，勾選要重新開機的星期和時間。
4. 在 **「動作」** 的程式欄輸入 `shutdown`，**「新增引數」** 欄輸入 `/r`。

![開啟工作排程器，建立工作](/images/群益安裝說明/26.png)

![觸發程序選每週，勾選重開機時間](/images/群益安裝說明/27.png)

![動作輸入 shutdown 和引數 /r](/images/群益安裝說明/28.png)

### 設定自動開啟 Joption

1. 一樣開啟 **「工作排程器」**，點 **「建立工作」**。
2. 在 **「觸發程序」** 選 **「每週」**，勾選要自動開啟的星期和時間。**時間要排在重開機之後。**
3. 在 **「動作」** 選取要執行的 Joption 程式（Joption.exe）。

![觸發程序設定自動開啟的時間](/images/群益安裝說明/29.png)

![動作選取 Joption.exe](/images/群益安裝說明/30.png)

## 8. 序號到期後更新

1. 向營業員索取更新後的序號。
2. 打開 Joption 資料夾裡 **conf** 目錄的 **pw.txt**。
3. 把**第三行**的內容整行換成新序號。
4. 存檔。

## 9. 程式改版更新

新版程式放在同一個下載資料夾，有兩種更新方式：

| | 方法一：只換執行檔 | 方法二：完整版 |
|---|---|---|
| **適合** | 已經在用、參數都調好了，不想重設 | 還沒安裝，或想換成完整新版 |
| **下載** | Joption 執行檔壓縮檔 | Joption 完整版壓縮檔 |
| **做法** | 解壓出 joption.exe 和 joption.pdb，覆蓋原資料夾的同名檔 | 解壓後，把舊程式 conf 裡的 PW.txt 和 mailconfig.txt 複製到新程式的 conf |
| **結果** | 原有設定全部保留 | 沿用原本的帳號密碼和郵件設定 |

> 裝不起來或卡在某一步，請找 LINE@ 歐大的官方客服，先裝好 AnyDesk 方便遠端協助。
