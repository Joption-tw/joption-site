#### 第一篇：打好基礎（入門篇）

1. **選擇權是什麼？**
    - 房子的比喻
2. **買方與賣方的世界**
    - 權利 vs 義務
    - 為什麼有人要當買方？有人要當賣方？
    - 對話漫畫：買方學生跟賣方房東討價還價
3. **四大基本部位**
    - Buy Call / Sell Call / Buy Put / Sell Put
    - 用生活例子：買樂透、買保險、收租金、簽賭單

#### 第二篇：認識時間與波動（核心篇）

1. **時間價值的祕密**
    - 為什麼時間是賣方的朋友？
    - 漫畫：蠟燭一天天變短 → 時間價值流失
2. **波動與VIX**
    - VIX 指數是什麼？
    - 波動像颱風，來的時候大家緊張，走了就平靜
3. **保證金與風險控管**
    - 為什麼保證金像「押金」
    - 如何避免「爆倉」

#### 第三篇：策略與應用（進階篇）

1. **賣方像收租：雙賣策略**
    - 賣Call + 賣Put → 收雙邊租金
    - 案例：房東同時出租一間房子 + 車位
2. **買方的夢與陷阱**
    - 買方就像買樂透，夢想大，但機率低
    - 為什麼大多數人買方會賠錢？
3. **對沖與調整**
    - Delta 中性
    - 加碼、減碼、停損機制
    - 插圖：天平的左右搖擺
