## 下載

[下載排程小幫手（安裝檔）](/files/排程小幫手_安裝程式_1.2.1.exe){.btn}

- 下載後雙擊安裝檔，按「安裝」就好，不用系統管理員權限。
- 如果跳出「**Windows 已保護您的電腦**」，按「**其他資訊**」，再按「**仍要執行**」。這是因為程式還沒有買數位簽章，不是中毒。
- 裝好後從**桌面**或**開始功能表**打開「排程小幫手」。

## 它能做什麼

| 要做什麼 | 說明 |
|---|---|
| 啟動程式 | 時間到就打開程式（例如 Joption.exe，捷徑也可以） |
| 關閉程式 | 時間到把程式關掉 |
| 重新開機 | 時間到就重新開機 |
| 關機 | 時間到就關機 |
| 休眠 | 很省電，而且之後可以被排程叫醒 |
| 睡眠 | 一般的睡眠 |
| 喚醒電腦 | 把休眠中的電腦叫醒 |

時間可以選「**平日（一～五）**」「每天」「每週指定幾天」「只跑一次」或「登入 Windows 時」。

## Joption 推薦設定：每天重開機＋自動開 Joption

![排程小幫手主畫面：設好「每天重開機」和「開 Joption」兩個排程](/images/群益安裝說明/10.png){.wide}

按「＋ 新增」，設兩個排程：

| 排程名稱 | 要做什麼 | 哪幾天 | 時間 |
|---|---|---|---|
| 每天重開機 | 重新開機 | 平日（一～五） | 05:40 |
| 開 Joption | 啟動程式，按「瀏覽…」選 `C:\Capital\Joption雙賣平衡下單機\Joption.exe` | 平日（一～五） | 08:31 |

![新增排程：要做什麼選「啟動程式」，選好 Joption.exe 和時間，按「儲存」](/images/群益安裝說明/11.png)

- **開 Joption 的時間要排在早上 8:31 以後**（也就是重開機之後）。
- 重開機、關機前會先跳出**倒數視窗**（預設 60 秒），這時候還在用電腦的話，可以按「取消」或「延後 10 分鐘」。
- 設好之後**視窗可以直接關掉**，排程照樣會跑。

> **重要：** 重開機後，電腦要能**自動登入到桌面**（不用打密碼），排程才打得開 Joption。如果開機會停在輸入密碼的畫面，Joption 就不會被打開。

## 主畫面按鈕

| 按鈕 | 用途 |
|---|---|
| ＋ 新增 | 新增一個排程 |
| 編輯 | 修改選到的排程 |
| 啟用 / 停用 | 暫時不想跑，先停用，不用刪掉 |
| 立即測試 | 馬上執行一次看看 |
| 刪除 | 刪掉選到的排程 |
| 執行紀錄 | 看每次有沒有成功執行 |
| 匯出設定 / 匯入設定 | 換電腦時把排程搬過去 |

> **小心「立即測試」：** 對「重新開機」或「關機」按立即測試，電腦會**真的**重開或關機。建議只測「開 Joption」那一個。

## 常見問題

#### 視窗關掉還會跑嗎？

會。排程是交給 Windows 執行的，排程小幫手的視窗開不開都沒關係。

#### 時間到了 Joption 沒有打開？

1. 確認電腦有**自動登入到桌面**（沒有停在輸入密碼的畫面）。
2. 打開排程小幫手，看「開 Joption」那一行有沒有出現「⚠ 找不到程式」。有的話按「編輯」，重新選一次 Joption.exe。
3. 按「執行紀錄」，看那個時間有沒有執行、有沒有錯誤訊息。

#### 電腦關機了，可以叫它自動開機嗎？

**完全關機**的電腦叫不醒。如果想要「晚上關、早上自動開」，晚上請用「**休眠**」收工，早上再設一個「**喚醒電腦**」（或在開程式的排程勾「喚醒」）。筆電通常要**插著電**才叫得醒。

#### 換一台電腦，排程要重設嗎？

不用。在舊電腦按「**匯出設定**」，會產生一個「排程小幫手設定.json」。把它放在新電腦的安裝檔旁邊再安裝，就會自動帶入；已經裝好的話，按「**匯入設定**」選這個檔就好。

#### 怎麼移除？

到 Windows「設定 → 應用程式」找到「排程小幫手」按解除安裝。已經設定的排程會一起刪除。
